# Feature modules (Feature-Sliced Design)

Каждый слайс — предметный сценарий приложения (`auth`, `tasks`, `objects`, `workspace`) — делится на сегменты:

- `api/` — обращения к Supabase (контракты см. в CONTRACT.md);
- `model/` — хуки состояния и бизнес-логика;
- `ui/` — компоненты экранов слайса;
- `index.ts` — публичный API слайса. Межслайсовые импорты — только через него.

Общие компоненты, модели и клиент остаются в `components/`, `types/` и `lib/`.
