# Прораб — мини-CRM объектов и задач

Стартовый проект на React, TypeScript, Vite, Mantine UI и Supabase. Интерфейс на русском, открытая регистрация не используется.

## Структура

```text
src/
  app/          приложение и глобальные стили
  components/   общие UI-компоненты
  features/     модули предметных областей
  lib/          клиенты внешних сервисов (Supabase)
  types/        общие типы и модели
  main.tsx      точка входа и провайдеры
supabase/
  migrations/   версии схемы базы данных
```

## Запуск

1. Установите Node.js 20.19+ или 22.12+.
2. В этой папке запустите `npm install`.
3. Создайте проект Supabase и выполните `supabase/migrations/202611060001_initial_schema.sql` через Supabase CLI или SQL Editor.
4. В Supabase отключите публичную регистрацию: Authentication → Providers → Email → Allow new users to sign up.
5. Создайте аккаунты вручную через Authentication → Users. Добавьте профиль каждому пользователю в SQL Editor, используя UUID Auth:

   ```sql
   insert into public.profiles (id, display_name, role)
   values ('UUID_ИЗ_AUTH', 'Имя', 'poster'); -- или executor
   ```

6. Скопируйте `.env.example` в `.env`, задайте `VITE_SUPABASE_URL` и публичный `VITE_SUPABASE_ANON_KEY`.
7. Запустите `npm run dev` для разработки. Перед сборкой можно отдельно запустить `npm run lint` и `npm run typecheck`; production-сборка выполняется командой `npm run build`, локальный просмотр — `npm run preview`.

Публичный anon/publishable key рассчитан на клиент и ограничен RLS. Ключ `service_role` запрещено добавлять в клиентский `.env` или Git.

## Модель доступа

RLS включён на всех таблицах. Постановщик видит все объекты и задачи; исполнитель — назначенные ему задачи и связанные объекты. Переход статуса проверяет триггер базы. Допустимы только переходы из спецификации; при возврате на доработку функция `transition_task` требует комментарий. Историю записывает триггер; API не может вставить, изменить или удалить записи истории.

## Статус

Инициализированы авторизация, обзор объектов/задач и базовая схема безопасности. Не завершены формы управления объектами/задачами, карточка истории, демонстрационные данные и деплой. Для облачного запуска нужны Supabase-проект и платформа хостинга; учётные данные в репозиторий не включаются.
